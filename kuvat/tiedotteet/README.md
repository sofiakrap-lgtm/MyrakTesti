# Tiedotteiden kuvat

Tähän kansioon tulevat tiedotekohtaiset kuvat. Ensimmäinen kuva (`-1.jpg`) on
tiedotteen pääkuva, jota klikkaamalla karuselli aukeaa. Loput näkyvät vain
karusellissa.

Kytkentä tehdään `aktiiviset.js`:ssä tiedotteen `gallery`-kentässä.
Jos tiedostoa ei ole, pääkuva piilotetaan automaattisesti — sivu ei näytä
rikkinäistä kuvaa.

## Huomioita

- Tiedostopääte pienellä (`.jpg`), ei `.JPG`. Palvelin erottelee kirjainkoon.
- Nimissä ei välilyöntejä eikä ääkkösiä.
- Suositeltu leveys 1600–2000 px, laatu 80 %. Karuselli skaalaa kuvan
  automaattisesti, mutta yli 3 Mt:n kuvat hidastavat sivua turhaan.
